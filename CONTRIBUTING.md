# Contributing to WOLF3D

WOLF3D was built by a fixed team during the Epitech curriculum. Issues and pull requests are welcome.

## Project layout

The game is in `src/` (raycasting, rendering, menus, events), its headers in `include/` and the helper library in `lib/my/`. Maps, textures, sprites and sounds are in `ressources/`. See the [README](README.md) to build and run it.

## Workflow

1. Open an issue describing the bug or the change.
2. Create a branch from `main`: `feature/<topic>` or `fix/<topic>`.
3. Commit with the convention of the history: `type(scope): summary`, e.g. `feat(menu): add panel for bg menu`.
4. Open a pull request into `main` with a short list of the changes and `Closes #<issue>`.

## Code style

- Follow the Epitech C coding style.
- No warnings under `-Wall -Wextra`.

## Code of conduct

By contributing you agree to follow the [code of conduct](CODE_OF_CONDUCT.md).
